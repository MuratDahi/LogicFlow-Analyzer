# LogicFlow Analyzer

A Java-based tool that parses Boolean expressions, analyzes gate hierarchy levels, and computes logical results[cite: 1, 2, 3].

## 🚀 Features

- **Automated Level Analysis:** Identifies circuit depth and gate types (AND, OR, NOT)[cite: 2].
- **Interactive Solver:** Prompts for variable inputs and calculates the final Boolean result[cite: 3].
- **Dynamic Parsing:** Reads expressions directly from `boole.txt`[cite: 2].
